# NR3053 — MicroScale v0.2.2 live deployment (2026-11-13)

## Scope and privacy

Physical OpenWrt ARM64 NR3053 with no `/dev/net/tun` and no TUN module.
Only diagnostic statuses and numerical measurements are recorded here;
Tailnet addresses, hostnames, secrets, state, raw command logs and service URLs
are intentionally excluded. This is a **single-session** functional test including two full router reboots, not an assertion of long-term uptime or full feature compatibility.

## Release candidate and verified published artifact

- Upstream Tailscale: v1.104.5, pinned source SHA `73a48057aaf5f60e4f770b398e9b7af576b01dbe`.
- Micro build uses upstream feature tags to retain userspace netstack,
  outbound SOCKS5 proxy, Serve, SSH, health status, DNS, ACME and networking.
- New combined ARM64 executable: **20,578,464 bytes (19.63 MiB)**.
- Physical test candidate SHA256: `3590adb169aeaac41d6d2e9db8175b1a03f78685c97592aa9ed429854ea71674`.
- **Final deployed binary (GitHub stable release v0.2.2):** SHA256
  `aa70837fcdb64768f2c30cbdd844fc03aead7fc820ec61bccf11afefbbe5ea75`.
  The downloaded ARM64 archive passed its sidecar SHA256 and embedded
  `SHA256SUMS` checks; its daemon passed the isolated userspace/SOCKS5/IPC test.
- Both candidates are 20,578,464 bytes and use the same pinned Tailscale commit,
  Go 1.27.3, build tags and features. The local candidate's Go module build-info
  records `v1.104.5`, while CI's published build records the pseudo-version for
  that identical commit; byte-for-byte hashes therefore differ. The official
  GitHub binary was explicitly installed and validated after a second reboot.
- Extreme ARM64 UPX-packed executable measured: **5,329,884 bytes (5.08 MiB)**;
  Extreme was **not** installed on this device.

The initial reduced profile failed to start on the device because it omitted
netstack and the SOCKS5 flag. A feature-restored but health-less candidate ran
its VPN and Serve functions yet incorrectly reported its own node offline.
Adding the health feature corrected the local self-online status. The final
profile was installed to flash and the existing Tailscale procd service was
restarted, then a full physical router reboot was performed. The daemon
started automatically and all network checks passed. The independently
checksummed published release artifact was then tested in RAM, installed,
restarted and validated with a second router reboot. Five Serve endpoints,
HTTPS proxy responses and end-to-end SSH through the Serve TCP forwarding port
remained working. A post-boot change in the display order of two TCP Serve
entries did not alter the set of routes or their reachability.

The original executable pair, procd service script and daemon state were
SHA256-backed up to a restricted directory on a separate Arch host prior to
replacing binaries. The router stores a marker for external rollback; its
`microscale uninstall` refuses to remove anything without on-device originals.
An Arch host restore script is maintained outside this public repository.

## Not yet tested

24-hour sustained operation, Exit Node, subnet routing and all optional
Tailscale features. Exit Node was intentionally disabled by owner
request. This report is not a certification for other devices or topologies.
