# NR3053 — MicroScale v0.2.2 live deployment (2026-11-13)

## Scope and privacy

Physical OpenWrt ARM64 NR3053 with no `/dev/net/tun` and no TUN module.
Only diagnostic statuses and numerical measurements are recorded here;
Tailnet addresses, hostnames, secrets, state, raw command logs and service URLs
are intentionally excluded. This is a **single-session** functional test, not
an assertion of long-term uptime or full feature compatibility.

## Release candidate

- Upstream Tailscale: v1.104.5, pinned source SHA `73a48057aaf5f60e4f770b398e9b7af576b01dbe`.
- Micro build uses upstream feature tags to retain userspace netstack,
  outbound SOCKS5 proxy, Serve, SSH, health status, DNS, ACME and networking.
- New combined ARM64 executable: **20,578,464 bytes (19.63 MiB)**.
- New binary SHA256: `3590adb169aeaac41d6d2e9db8175b1a03f78685c97592aa9ed429854ea71674`.
- Extreme ARM64 UPX-packed executable measured: **5,329,884 bytes (5.08 MiB)**;
  Extreme was **not** installed on this device.

The initial reduced profile failed to start on the device because it omitted
netstack and the SOCKS5 flag. A feature-restored but health-less candidate ran
its VPN and Serve functions yet incorrectly reported its own node offline.
Adding the health feature corrected the local self-online status. The final
profile was installed to flash and the existing Tailscale procd service was
restarted; no router reboot was performed.

The original executable pair, procd service script and daemon state were
SHA256-backed up to a restricted directory on a separate Arch host prior to
replacing binaries. The router stores a marker for external rollback; its
`microscale uninstall` refuses to remove anything without on-device originals.
An Arch host restore script is maintained outside this public repository.

## Not yet tested

24-hour sustained operation, full router reboot, Exit Node, subnet routing and
all optional Tailscale features. Exit Node was intentionally disabled by owner
request. This report is not a certification for other devices or topologies.
